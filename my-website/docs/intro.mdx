# Mexe-Mexe

Mexe-Mexe é um jogo de cartas desenvolvido em Python com Pygame. Esta
documentação descreve as regras implementadas, as entidades principais e a
organização do código.

## Executar o jogo

Na raiz do projeto, instale a dependência e inicie a aplicação:

```bash
python -m venv venv
pip install -r requirements.txt
python main.py
```

No Windows, ative o ambiente virtual com `venv\Scripts\activate`.

## Organização

- `src/entidades/`: cartas, baralho, jogadores e partida.
- `src/regras/`: validação de combinações.
- `src/mundo/`: estado das combinações sobre a mesa.
- `src/ui/`: menu, tutorial, placar, configurações e interface da partida.
- `assets/`: imagens, fundos e sons.

O desenho das cartas fica em componentes de interface independentes da lógica.
Essa separação permite substituir o desenho atual por imagens e sprites sem
mudar as regras do jogo.
