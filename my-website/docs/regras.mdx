# Regras

## Regras gerais

- Regra 1: O objetivo de cada jogador é formar combinações com as cartas de sua mão e descartá-las na mesa.
- Regra 2: Trincas são válidas com pelo menos 3 cartas de mesmo número/valor, mesmo com naipes repetidos.
- Regra 3: Sequências são válidas com no mínimo 3 cartas do mesmo naipe, com números sequeciais.
- Regra 4: As combinações presentes na mesa são "comunitárias", podendo ser alteradas pelos jogadores, desde que mantendo o número mínimo de cartas.
- Regra 5: Caso o jogador não tenha nenhuma carta para "ajudar" nos jogos da mesa, puxa uma carta do baralho (não há monte para descarte/lixo).
- Regra 6: As jogadas e combinações possíveis dependem da capacidade de análise de cada jogador para utilizar das cartas em mesa para complementar o que possuem em mão.
- Final do jogo: Quando um jogador atinge a condição de vitória (descarte das cartas em mão), os demais somam os pontos para definir o ranking entre os jogadores.
